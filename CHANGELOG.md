# Changelog

## 1.2.0
- Code reorganized into small modules. Nothing changes for players.
- Fix: negative differences were rounded one point too far (−40% showed as −41%).

## 1.1.1
- Display scale is now a slider (0.5x to 3.0x).

## 1.1.0
- Minimap button: left-click opens settings, right-click toggles the display, drag to move it.
- Settings window, opened with `/fspeed`, the minimap button, Alt-click on Titan, or Options → AddOns.
- Options to hide the floating display and the minimap button.
- Titan Panel bar options: choose which values to show, labels, colors, and units.

## 1.0.0
- First release: your speed, your target's speed and the difference, in a floating box and as a Titan Panel / LibDataBroker plugin.
